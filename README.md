### 🛒 Full-Stack E-Commerce Platform — MERN Stack

<div align="center">

[![Live Demo](https://img.shields.io/badge/🌐_Live_Demo-Visit_Site-00D9FF?style=for-the-badge)](https://e-commerce-frontend-self-eight.vercel.app/)
&nbsp;&nbsp;
[![GitHub Repo](https://img.shields.io/badge/GitHub-Source_Code-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Chinmaya2438/E-Commerce-Website)

</div>

```
Stack: Node.js · Express.js · MongoDB · React (Vite) · Tailwind CSS · Stripe · Cloudinary
```

- 🔐 **Secure Auth System** — JWT + bcrypt with protected routes and persistent sessions
- 🏪 **Admin Dashboard** — full CRUD for products, orders, users, and coupon management
- 💳 **Stripe Payment Gateway** — real checkout sessions with backend payment verification
- ☁️ **Cloud Media Pipeline** — Cloudinary + Multer for product image uploads and storage
- 🎟️ **Coupon & Discount Engine** — percentage and flat-rate codes with order-level validation
- 🧾 **PDF Invoice Generation** — auto-generated invoices on order completion
- 📦 **Order Tracking** — full lifecycle from cart to delivery with status updates
- ⚡ **SPA Frontend** — React (Vite) + Tailwind CSS + Context API for global state management
- 🚀 **Fully Deployed** — Frontend on **Vercel**, Backend on cloud infrastructure
